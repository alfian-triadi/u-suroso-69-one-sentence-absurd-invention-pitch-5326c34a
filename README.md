One absurd invention pitch for the make.fun bounty "One-Sentence Absurd Invention Pitch" — a single sentence about a toaster that turns burnt breakfast into a labor dispute.

> A toaster that gives up on browning your bread and instead prints a tiny receipt — 'the crumbs have unionized, talks resume Tuesday' — so burnt toast becomes a labor dispute instead of your failure.

(198 characters, one sentence.)

## Run

```sh
node main.ts
```

This writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).
